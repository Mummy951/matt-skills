---
name: research
description: 基于高可信度的一手资料对某个问题展开调研，并将结论整理为仓库中的一个 Markdown 文件。当用户希望调研某个主题、收集文档或 API 事实，或将阅读类准备工作委派给后台智能体时使用。
---

启动一个**后台智能体**来做调研，这样你可以在它阅读资料的同时继续工作。给它一个全新的上下文窗口再启动。

它的任务：

1. 基于**一手资料**（官方文档、源代码、规格、一方 API）调研该问题，而不是基于对这些资料的二手转述。把每一条结论追溯到其来源归属处。
2. 将结论写入单个 Markdown 文件，并为每条结论标注来源。
3. 保存到仓库中存放此类笔记的既有位置；遵循现有惯例；如果没有既有惯例，就放在一个合理的位置，并说明放在了哪里。
